# Ultimate Prompt Builder - 要件定義書

## 概要
日本語で選択・入力するだけで、AI画像生成ツール（Nano Banana Pro / Imagen 3 等）向けの
プロフェッショナルな英語プロンプトを自動生成するWebアプリケーション。

## ターゲットユーザー
- AI画像生成ツールを使いたいが、英語プロンプトの書き方が分からない日本語ユーザー
- プロの写真家・映画監督レベルの技術用語をプロンプトに盛り込みたいクリエイター

## 技術スタック
| 項目 | 技術 |
|------|------|
| フレームワーク | React 19 + TypeScript |
| ビルドツール | Vite 6 |
| CSSフレームワーク | Tailwind CSS (CDN) |
| アイコン | Lucide React |
| フォント | Inter (Google Fonts) |
| 翻訳 | クライアントサイド辞書ベース（API不要） |

## 主要機能

### 1. 被写体入力（日本語）
- テキストエリアで自由入力
- 日本語→英語のローカル辞書翻訳（170語以上対応）

### 2. 8カテゴリのパラメータ選択
| # | カテゴリ | 内容 |
|---|---------|------|
| 1 | 基本設定 | 被写体入力 + アスペクト比 (16:9, 9:16, 1:1, 2.35:1, 4:3) |
| 2 | カメラ機材 | 85mmポートレート, 35mmストリート, 100mmマクロ, ティルトシフト, 魚眼, ドローン空撮 |
| 3 | フィルムと質感 | 8Kデジタル, Kodak Portra, Fujifilm Velvia, モノクロ, VHSグリッチ |
| 4 | 照明と大気 | ボリュメトリック, レンブラント, サイバーパンクネオン, ゴールデンアワー, コースティクス |
| 5 | 時間と動き | 瞬間冷凍, 長時間露光, 流し撮り, 標準 |
| 6 | 構図と視線 | リーディングライン, 三分割法, ネガティブスペース, フレーム・イン・フレーム, ダッチアングル |
| 7 | 質感レンダリング | サブサーフェス, オクタンレンダー, インパスト油絵, 実写 |
| 8 | スタイル・世界観 | ソーラーパンク, コテージコア, サイバーパンク, スチームパンク, ウェス・アンダーソン, ノーラン, 新海誠 |

### 3. プロンプト自動生成
- 品質プレフィックス + 翻訳済み被写体 + 各パラメータ + 品質サフィックス + アスペクト比
- ワンクリックでクリップボードにコピー

### 4. UIデザイン
- ダークモードベースのモダンUI
- アコーディオン型セクション（選択状態をサマリー表示）
- 固定フッターの生成ボタン
- レスポンシブ対応（モバイル〜デスクトップ）

## ファイル構成
```
画像生成-主役/
├── index.html          # エントリポイント（Tailwind CDN, フォント読み込み）
├── index.tsx           # React マウント
├── index.css           # カスタムCSS（アニメーション等）
├── App.tsx             # メインレイアウト
├── types.ts            # TypeScript型定義
├── constants.ts        # 全選択肢データ
├── components/
│   ├── PromptGenerator.tsx  # メインロジック（状態管理, 生成処理）
│   └── Accordion.tsx        # アコーディオンUIコンポーネント
├── services/
│   └── geminiService.ts     # ローカル辞書翻訳エンジン
├── package.json
├── tsconfig.json
└── vite.config.ts
```

## 非機能要件
- APIキー不要（完全クライアントサイド）
- ビルド後のバンドルサイズ: ~222KB (gzip: ~72KB)
- 起動時間: <400ms（Vite dev server）
